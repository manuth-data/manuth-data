## 🚀 Featured Projects
 
🔗 **[Financial-Fraud-Detection-System](https://github.com/manuth-data/Financial-Fraud-Detection-System.)**
End-to-end fraud classification pipeline. EDA on 3.6M transaction rows; Logistic Regression model reaching ~94.5% accuracy; deployed via Streamlit.
 
🔗 **[Credit-Risk-Modeling-Using-Machine-Learning](https://github.com/manuth-data/Credit-Risk-Modeling-Using-Machine-Learning)**
Predicts good vs. bad credit risk. XGBoost model tuned with GridSearchCV to ~67.6% accuracy; deployed via Streamlit.
 
🔗 **[Customer-Behavior_Dashboard-Analyst](https://github.com/manuth-data/Customer-Behavior_Dashboard-Analyst)**

Normalized database for employee and IT asset management with audit logging and role-based access control.
